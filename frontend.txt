# Frontend Implementation Guide - Quiz Creation & Progression

## Overview
This guide explains how to implement the frontend for the quiz creation and progression features based on the updated API. The system now supports hybrid quiz creation where users can manually create questions and/or auto-generate them from deck categories.

## API Endpoints

### Quiz Creation
**Endpoint:** `POST /quiz`
**Purpose:** Create a new quiz with hybrid question sources

### Request Structure
```typescript
interface CreateQuizRequest {
  title: string;
  description?: string;
  manual_questions?: ManualQuestionRequest[];
  auto_generate?: AutoGenerateRequest;
  is_public: boolean;
  // Admin-only fields (only shown if user is admin)
  pass_percentage?: number;
  gives_coins?: boolean;
  coin_reward?: number;
  level_order?: number;
  prerequisite_quiz_id?: number;
  is_system?: boolean;
}

interface ManualQuestionRequest {
  question_text: string;
  correct_answer: string;
  options?: string[]; // Required for MCQ
  question_type: 'mcq' | 'write_word' | 'translate';
  direction: 'source_to_target' | 'target_to_source';
}

interface AutoGenerateRequest {
  deck_selections: DeckSelection[];
  question_types: ('mcq' | 'write_word' | 'translate')[];
  directions: ('source_to_target' | 'target_to_source')[];
  question_count: number;
  difficulty?: string;
}

interface DeckSelection {
  deck_id: number;
  categories: string[];
}
```

## Frontend Components Needed

### 1. Quiz Creation Form
Create a comprehensive form with two main sections:

#### Manual Questions Section
- **Question Builder Component**
  - Text input for question text
  - Text input for correct answer
  - Dynamic options array for MCQ (add/remove buttons)
  - Question type selector (MCQ, Write Word, Translate)
  - Direction selector (Source→Target, Target→Source)
  - Add/Remove question buttons
  - Validation for required fields

#### Auto-Generation Section
- **Deck/Category Selector**
  - Fetch available decks: `GET /quiz/decks`
  - For each selected deck, fetch categories: `GET /quiz/categories?deck_id={id}`
  - Multi-select for categories within each deck
  - Question count input per deck/category combination

- **Generation Settings**
  - Question type checkboxes (MCQ, Write Word, Translate)
  - Direction checkboxes (Source→Target, Target→Source)
  - Total question count slider/input
  - Difficulty selector (if supported)

#### Quiz Settings
- Title and description inputs
- Public/Private toggle
- Admin-only settings (conditionally shown):
  - Pass percentage
  - Coin rewards toggle and amount
  - Level order
  - Prerequisite quiz selector
  - System quiz toggle

### 2. Quiz List/Dashboard
**Endpoint:** `GET /quiz`
- Display user's created quizzes
- Show quiz metadata (title, description, question count, creation date)
- Action buttons: Edit, Start, Delete, Share (if public)

### 3. Quiz Taking Interface
**Endpoints:**
- `POST /quiz/{id}/start` - Start quiz session
- `POST /quiz/{id}/submit-answer` - Submit individual answers
- `GET /quiz/{id}/progress` - Get current progress

#### Quiz Session State
```typescript
interface QuizSession {
  id: string;
  session_id: string;
  title: string;
  current_index: number;
  questions: QuizQuestion[];
  progress: {
    answered: number;
    total: number;
    percentage: number;
  };
}

interface QuizQuestion {
  id: string;
  question_text: string;
  options?: string[]; // For MCQ
  question_type: 'mcq' | 'write_word' | 'translate';
  direction: 'source_to_target' | 'target_to_source';
}
```

#### Question Rendering Components
- **MCQ Component**: Radio buttons or cards for options
- **Write Word Component**: Text input with validation
- **Translate Component**: Text input with direction indicator

### 4. Progress Tracking
**Endpoints:**
- `GET /progression/stats` - Overall user progress
- `GET /progression/level` - Current level and XP
- `GET /quiz/{id}/progress` - Quiz-specific progress

#### Progress Dashboard
- Current level and XP progress bar
- Total quizzes completed
- Average scores
- Recent activity
- Achievement badges
- Coin balance (if applicable)

## Implementation Steps

### 1. API Client Updates
Update your API client to handle the new request/response structures:

```typescript
// Quiz creation
async createQuiz(data: CreateQuizRequest): Promise<QuizDetailResponse> {
  return this.post('/quiz', data);
}

// Deck/category fetching
async getDecks(): Promise<Deck[]> {
  return this.get('/quiz/decks');
}

async getCategories(deckId: number): Promise<Category[]> {
  return this.get(`/quiz/categories?deck_id=${deckId}`);
}
```

### 2. Form State Management
Use React state or a form library (Formik, React Hook Form) to manage:

```typescript
interface QuizFormState {
  title: string;
  description: string;
  manualQuestions: ManualQuestion[];
  autoGenerate: AutoGenerateConfig | null;
  isPublic: boolean;
  // Admin fields
  passPercentage?: number;
  givesCoins: boolean;
  coinReward: number;
  // ... other admin fields
}
```

### 3. Validation Logic
Implement client-side validation:

- At least one question source (manual or auto-generate)
- Manual questions: required fields based on type
- Auto-generate: at least one deck/category selected
- Question count limits
- Admin permission checks

### 4. Quiz Taking Flow
1. Start quiz → Get session ID
2. Render current question based on type
3. Submit answer → Update progress
4. Move to next question or show results
5. Handle quiz completion and scoring

### 5. Admin Features
Conditionally show admin controls based on user role:

```typescript
const isAdmin = useAuth().user?.is_admin;

if (isAdmin) {
  // Show admin-only fields
  // Handle system quiz creation
}
```

## UI/UX Considerations

### Quiz Creation Flow
1. **Landing Page**: Choose between "Create from Scratch" or "Use Templates"
2. **Question Builder**: Intuitive interface for manual questions
3. **Smart Suggestions**: Auto-complete for categories, question types
4. **Preview Mode**: Show how questions will appear to users
5. **Save Drafts**: Allow saving incomplete quizzes

### Quiz Taking Experience
1. **Progress Indicator**: Visual progress bar
2. **Question Navigation**: Optional back/forward (if allowed)
3. **Answer Feedback**: Immediate feedback for practice mode
4. **Time Tracking**: Optional timers for competitive quizzes
5. **Results Screen**: Detailed breakdown with explanations

### Progression System
1. **Level Visualization**: XP bars, level badges
2. **Achievement System**: Unlockables, streaks
3. **Leaderboards**: Compare with friends/class
4. **Personal Stats**: Historical performance charts

## Error Handling
- Network errors during quiz creation
- Invalid question data
- Permission errors for admin features
- Quiz session timeouts
- Database conflicts (rare)

## Performance Considerations
- Lazy load deck/category data
- Paginate quiz lists
- Cache user progress locally
- Optimize question rendering for large quizzes
